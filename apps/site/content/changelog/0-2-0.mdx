### Changed

- Public API 1.1.0: records no longer carry `provenance` or `source_license`. They carry `as_of` and `official_url`, a link to the court's own copy or `null`.
- The order `url` and the notice `url` fields are replaced by `official_url`.

### Added

- A [Data sources and licences](/legal/data-sources/) page with the attribution each source licence requires.
