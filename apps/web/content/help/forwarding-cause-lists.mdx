Every member has a private intake address.

## Set up

- Create the address in **Settings, Email intake**.
- Add the senders you trust to the allow-list.
- Forward a cause list or order to the address.

Mail from other senders is ignored. Rotate or revoke the address at any time.

This is software documentation, not legal advice.
