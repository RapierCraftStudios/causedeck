# A0 evaluation (#56)

`thresholds.json` is the bar the A0 generic adapter must clear on the FICTIONAL golden set
(`fixtures/generic.a0`, `fixtures/in.ka.bengaluru-urban.district`, `fixtures/in.tn.chennai.district`)
and on documents generated by seed (`packages/intelligence/src/generic-a0/synthetic/generate.ts`):

- row precision at least 98%;
- anchor validity 100% (every anchor's quote is verbatim at its offsets on its page);
- zero hallucinated dates (an accepted absolute date is always written in its quote);
- at least 12 fixtures per forum id.

`packages/intelligence/src/generic-a0/__tests__/golden-metrics.test.ts` runs the whole pipeline (skeleton, a recorded model
with injected faults, validators) against it. Real district fixtures (40 orders each, docs/strategy/11 §4)
are validated later with #119 and are not needed to merge.

Regenerate the committed fixtures after a deliberate change (from `packages/intelligence`), then run Prettier and review:

```
node --experimental-strip-types -e \
  "import('./src/generic-a0/synthetic/generate.ts').then((m) => m.writeA0Fixtures())"
```

Corrections made in the confirmation grid enter an eval set only when the workspace allows eval reuse
(default off) and the person consented per item (`exportableForEval`).
